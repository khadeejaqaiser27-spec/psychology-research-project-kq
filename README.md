# Study Habits and Student Well-being

## Project Description
This is a fictional psychology class project about study habits and student well-being. It explores how students organize their study time and develop effective learning routines.

## Project Objectives
- To understand the importance of good study habits.
- To explore different study techniques.
- To learn how time management supports learning.
- To organize project information in one place.

## Project Scope
This project uses fictional and non-sensitive information for educational purposes.

## Team
This project is prepared by a student team as part of a psychology class activity.

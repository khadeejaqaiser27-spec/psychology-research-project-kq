# University Event Management

## Project Description
This project is about planning and organizing fictional university events. It helps students understand how to manage event schedules, organize activities, and work together as a team.

## Project Objectives
- To learn the basics of event planning.
- To organize university event schedules.
- To assign tasks to team members.
- To improve teamwork and communication skills.

## Project Title
University Event Management

## Purpose
This fictional project helps students learn how to plan and organize university events. It explains how schedules, team responsibilities, and proper communication can make an event successful.

## Files
